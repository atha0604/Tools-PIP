⬇ Unduh Data Siswa PIP

Tanpa memasang aplikasi apa pun. Cukup 3 langkah.

Untuk admin: alamat sumber script belum diisi. Ubah baris SUMBER di bagian bawah file ini, sesuai petunjuk di sana.

1Pasang tombol (sekali saja)

Tampilkan bilah bookmark Chrome dengan menekan Ctrl + Shift + B. Lalu seret tombol hijau ini ke bilah bookmark di bagian atas browser:

⬇ Unduh Data PIP
Kalau tombol tidak bisa diseret, klik kanan tombol, pilih Bookmark link ini (atau Tambahkan tautan ke bookmark).

2Buka halaman Pengusulan

Login PIP dengan akun Dinas, lalu buka menu Pengusulan. Tunggu sampai daftar sekolah tampil.

3Klik tombol bookmark tadi, lalu pilih unduhan

Di pojok kanan bawah muncul panel ⬇ Unduh Data Siswa. Pilih salah satu:

  • Excel gabungan semua sekolah: satu file berisi rekap per kecamatan dan data semua siswa.
  • ZIP file Excel per sekolah: satu file Excel untuk tiap sekolah, dikelompokkan per kecamatan.
Tunggu sampai selesai dan jangan menutup tab. File terunduh otomatis. Kalau ada sekolah yang gagal, tekan Ulangi sekolah yang gagal. Tombol Stop menghentikan proses.

Kalau tidak berhasil

  • Pastikan akun yang dipakai adalah akun Dinas dan halaman Pengusulan sudah terbuka.
  • Klik bookmark lagi setiap kali halaman PIP dimuat ulang (refresh).
  • Pastikan internet aktif. Bookmark memuat programnya dari internet.
Cara lain: tempel kode di Console (untuk yang terbiasa)

Tekan F12 → tab Console → tempel kode di bawah → Enter. (Chrome meminta mengetik allow pasting dulu.)

Data siswa berisi NIK dan nama orang tua. Simpan hasil unduhan dengan aman dan jangan disebarkan.
